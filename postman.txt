=============================================
 ZAWAGE - POSTMAN API REFERENCE
 Base URL: http://127.0.0.1:8000/api
 Headers for authenticated routes:
   Authorization: Bearer {token}
   Accept: application/json
   Content-Type: application/json
=============================================

===========================

   }

---------------------------------------------------
2. POST /register
   Description: Register a new female user
   Auth: No
   Body (JSON):

     "password": "fatma1234"

   Auth: No
   Body (JSON):
   {
     "email": "fatma@example.com",

===========================
  ADMIN ROUTES
===========================

---------------------------------------------------
GET /admin/stats
   Auth: Bearer Token + Admin
   Body: None
---------------------------------------------------

---------------------------------------------------
GET /admin/users
   Auth: Bearer Token + Admin
   Body: None
---------------------------------------------------

---------------------------------------------------
PUT /admin/users/{id}
   Auth: Bearer Token + Admin
   Body (JSON):
   {
     "name": "اسم جديد",
     "email": "new@example.com",
     "role": "user"
   }
---------------------------------------------------

---------------------------------------------------
DELETE /admin/users/{id}
   Auth: Bearer Token + Admin
   Body: None
---------------------------------------------------

---------------------------------------------------
POST /admin/users/{id}/toggle-ban
   Auth: Bearer Token + Admin
   Body: None
---------------------------------------------------

---------------------------------------------------
GET /admin/reports
   Auth: Bearer Token + Admin
   Body: None
---------------------------------------------------

---------------------------------------------------
PUT /admin/reports/{id}
   Auth: Bearer Token + Admin
   Body (JSON):
   {
     "status": "resolved"
   }
---------------------------------------------------
