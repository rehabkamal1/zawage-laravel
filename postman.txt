===========================
  SUBSCRIPTIONS & PAYMENTS
===========================

---------------------------------------------------
1. POST /subscriptions/subscribe
   Description: Initiate a daily (100 EGP / 5 views) or monthly (300 EGP / 20 views) subscription.
                Supports real Paymob checkout or mock simulation mode (if credentials are empty).
   Auth: Bearer Token
   Body (JSON) - Vodafone Cash Example:
   {
     "type": "daily",
     "payment_method": "vodafone_cash",
     "wallet_number": "01012345678"
   }
   
   Body (JSON) - InstaPay Example:
   {
     "type": "monthly",
     "payment_method": "instapay"
   }

   Response (Mock Mode Fallback):
   {
     "message": "تم إنشاء طلب الاشتراك بنجاح (وضع تجربة الدفع النشط)",
     "is_mock": true,
     "subscription_id": 1,
     "payment_id": 1,
     "amount": 100,
     "payment_method": "vodafone_cash",
     "checkout_url": "http://localhost:8000/api/subscriptions/1/simulate-payment-page"
   }
---------------------------------------------------

---------------------------------------------------
2. POST /subscriptions/{id}/simulate-payment
   Description: Simulate a successful payment check for the pending subscription.
                This instantly activates the subscription and completes the payment.
   Auth: No (Public / Clicked from redirect page)
   Body: None
   Response: HTML page indicating success.
---------------------------------------------------

---------------------------------------------------
3. POST /matches/{id}/contact
   Description: Click "Contact via WhatsApp" for a match. 
                - If the viewer is female, returns groom's personal phone and WhatsApp link immediately.
                - If the viewer is male:
                  * Checks if he has an active subscription.
                  * Checks if he already contacted this bride under the active subscription.
                  * If first time, checks for remaining attempts, decrements 1 attempt, and records contact.
                  * Returns ONLY the bride's guardian phone and guardian WhatsApp link.
   Auth: Bearer Token
   Body: None
